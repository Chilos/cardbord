# 🎯 Cardbord - Interactive Card Grid Plugin for Logseq

[![Version](https://img.shields.io/badge/version-0.1.0-blue.svg)](package.json)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)

Интерактивный плагин для Logseq, позволяющий создавать сетки с карточками для визуальной организации информации.

## 🌟 Возможности

### ✅ Уже реализовано (v0.1.0)
- ⚡ **Slash-команда `/cardbord`** - быстрое создание сетки
- 🎨 **Автоматическая стилизация** - адаптация к теме Logseq 
- 📱 **Адаптивный дизайн** - корректное отображение на всех устройствах
- 🎯 **Базовая функциональность** - создание карточек кликом по `+`
- 🏷️ **Заголовки строк и столбцов** - структурированная организация
- 🎨 **6 цветов карточек** - визуальная категоризация
- 💾 **Автосохранение** - данные сохраняются в блоке Logseq

### ✅ Реализовано
- 🖱️ **Drag & Drop** - перетаскивание карточек между ячейками
- 📝 **Модальное редактирование** - полнофункциональный редактор
- 📚 **Стекирование карточек** - несколько карточек в одной ячейке (до 10 штук)
- ⚙️ **Управление гридом** - добавление/удаление строк и столбцов
- 🎨 **Система тем** - автоматическая адаптация к теме Logseq

### 🚧 В разработке
- 🔗 **Умные стрелки** - связи между карточками с обнаружением пересечений
- 🎨 **Цветовая палитра** - выбор цветов для карточек
- 🔧 **Расширенное редактирование** - текстовые поля, чекбоксы
- 📤 **Экспорт** - сохранение грида как изображение

## 🚀 Установка

### Способ 1: Автоматическая установка
1. Скачайте плагин из Logseq Marketplace (планируется)

### Способ 2: Ручная установка
1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/logseq-cardbord-plugin.git
   cd logseq-cardbord-plugin
   ```

2. Установите зависимости и соберите проект:
   ```bash
   npm install
   npm run build
   ```

3. Установите в Logseq:
   - Откройте Logseq → Settings → Plugins
   - Включите "Developer mode" 
   - Нажмите "Load unpacked plugin"
   - Выберите папку с проектом cardbord

### 🚨 Если плагин не загружается

См. подробную инструкцию в файле [`INSTALLATION.md`](./INSTALLATION.md) - там описаны все возможные проблемы и их решения.

## 📖 Использование

### Создание сетки
1. В любом блоке введите `/cardbord`
2. Автоматически создается сетка 2x3 с заголовками
3. Кликните по `+` в любой ячейке для добавления карточки

### Редактирование
- **Режим просмотра**: Карточки нельзя редактировать
- **Режим редактирования**: Кнопка ✏️ в правом верхнем углу (в разработке)

### Структура данных
Плагин сохраняет данные в формате JSON внутри блока Logseq:
```json
{
  "grid": {
    "rows": 2,
    "cols": 3,
    "headers": {
      "showRowHeaders": true,
      "showColHeaders": true,
      "rowHeaders": ["Строка 1", "Строка 2"],
      "colHeaders": ["Столбец 1", "Столбец 2", "Столбец 3"]
    },
    "cells": [...],
    "connections": [...]
  }
}
```

## 🎨 Темизация

Плагин автоматически адаптируется к текущей теме Logseq, используя CSS Custom Properties:

- `--ls-primary-background-color` → цвет фона грида
- `--ls-secondary-background-color` → цвет фона карточек  
- `--ls-primary-text-color` → цвет текста
- `--ls-border-color` → цвет границ
- `--ls-accent-color` → акцентный цвет
