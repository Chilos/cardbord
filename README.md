# Cardbord - Logseq Plugin

![Version](https://img.shields.io/badge/version-1.0.0-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

Визуальный плагин для Logseq, позволяющий создавать интерактивные сетки с карточками, связанными стрелками.

## ✨ Возможности

### 📋 Карточки и сетки
- **Настраиваемые сетки** - создавайте сетки любого размера (от 1x1 до 10x10)
- **Цветные карточки** - 10 цветовых тем для категоризации
- **Markdown поддержка** - используйте форматирование, ссылки `[[page]]` и теги `#tag`
- **Многострочный текст** - поддержка переносов строк
- **Автомасштабирование** - текст автоматически подстраивается под размер карточки

### 🔗 Стрелки и связи
- **Визуальные связи** - соединяйте карточки стрелками
- **Магнитные якоря** - стрелки автоматически привязываются к сторонам карточек (top/right/bottom/left)
- **Умная отрисовка** - стрелки становятся пунктирными при прохождении через другие карточки
- **Цветные стрелки** - те же 10 цветов для категоризации связей
- **Кривые Безье** - плавные изгибы для лучшей читаемости

### 🎨 Визуальный редактор
- **Drag & Drop** - перетаскивайте карточки по сетке
- **Интерактивное создание стрелок** - кликните на якорь и протяните к другой карточке
- **Заголовки колонок** - опциональные заголовки для структурирования данных
- **Управление размером** - изменяйте размер сетки с сохранением данных
- **Тёмная и светлая темы** - автоматическая адаптация к теме Logseq

## 📦 Установка

### Из релиза (рекомендуется)

1. Перейдите на страницу [Releases](https://github.com/Chilos/cardbord/releases)
2. Скачайте последний `cardbord-X.X.X.zip`
3. Распакуйте архив
4. В Logseq откройте `Settings → Plugins → Load unpacked plugin`
5. Выберите распакованную папку

### Из исходного кода

```bash
git clone https://github.com/yourusername/cardbord.git
cd cardbord
npm install
npm run build
```

Затем загрузите папку через `Load unpacked plugin` в Logseq.

## 🚀 Использование

### Создание сетки

**Способ 1: Slash команда (рекомендуется)**

Наберите `/` в Logseq и начните вводить "Cardbord Grid". Выберите команду из списка - будет создана сетка 2x2 по умолчанию.

**Способ 2: Ручной ввод макроса**

Вы также можете вручную вставить макрос:

```
{{renderer cardbord, <base64-encoded-data>}}
```

Примечание: Данные сетки хранятся в base64-кодированном формате JSON. Для создания новой сетки используйте slash команду.

### Редактирование

1. Наведите на сетку и нажмите **✏️** (иконка карандаша)
2. Откроется визуальный редактор

### Работа с карточками

**Добавить карточку:**
- Кликните на пустую ячейку с плюсом `+`
- Введите текст (поддерживается Markdown)
- Выберите цвет
- Нажмите "Добавить"

**Редактировать карточку:**
- Кликните на существующую карточку
- Измените текст или цвет
- Нажмите "Обновить"

**Переместить карточку:**
- Перетащите карточку мышью на новую позицию

**Удалить карточку:**
- Выберите карточку
- Нажмите "Удалить карточку"

### Работа со стрелками

**Создать стрелку:**
1. Наведите на карточку - появятся якоря (◆) по краям
2. Кликните на якорь и удерживайте
3. Протяните к якорю другой карточки
4. Отпустите - стрелка создана

**Изменить цвет стрелки:**
- Кликните на стрелку
- Выберите новый цвет
- Нажмите "Обновить стрелку"

**Удалить стрелку:**
- Кликните на стрелку
- Нажмите "Удалить стрелку"

### Заголовки колонок

1. Нажмите кнопку **📋 Заголовки колонок**
2. Введите названия для колонок
3. Для отключения нажмите кнопку повторно

### Изменение размера сетки

1. Используйте кнопки **➕** / **➖** для добавления/удаления строк и колонок
2. При уменьшении размера карточки за границей будут удалены

## 🎨 Форматирование текста

В карточках поддерживается:

- **Жирный текст** - `**текст**`
- *Курсив* - `*текст*`
- Ссылки на страницы - `[[Page Name]]`
- Теги - `#tag`
- Переносы строк - Enter в textarea

## ⚙️ Технические детали

### Стек технологий
- TypeScript
- Logseq Plugin API
- SVG для стрелок
- CSS Grid для сетки
- esbuild для сборки
- Vitest для тестирования

### Хранение данных
Данные сеток сохраняются в блоках Logseq в base64-кодированном JSON формате.

### Разработка

```bash
# Установка зависимостей
npm install

# Режим разработки с hot reload
npm run dev

# Сборка
npm run build

# Запуск тестов
npm test

# Запуск тестов с UI
npm run test:ui

# Покрытие кода тестами
npm run test:coverage
```

Проект покрыт юнит-тестами для основной функциональности:
- ✅ **Encoding/Decoding** - сериализация данных в base64
- ✅ **Geometry** - расчет позиций якорей и кривых Безье
- ✅ **Markdown** - парсинг и рендеринг форматирования

Запуск тестов: `npm test`
